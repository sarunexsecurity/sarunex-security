GOOGLE SEARCH CONSOLE:
1. Open https://search.google.com/search-console/
2. Select the verified URL-prefix property:
   https://sarunexsecurity.github.io/sarunex-security/
3. Open Sitemaps and submit: sitemap.xml
4. Use URL Inspection for the homepage and /founder.html.
5. Run Test Live URL, then choose Request Indexing if available.
